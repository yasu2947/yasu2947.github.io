# 한월 RPG 도깨비 스텟 계산기 사용법

# 주의 사항

* 현재 이미 스텟 또는 단전이 찍혀있는 상태라면
  최적화 진행 시 사용 포인트 / 사용 단전 포인트를
  이미 투자된 만큼 제외하고 입력해주세요.

예시:

* 총 포인트 500
* 현재 이미 300 사용중

→ 최적화 사용 포인트는 200 입력

---

* 가장 효율적인 최적화를 위해
  스텟 / 단전을 전부 초기화한 상태에서
  입력 및 최적화를 진행하는 것을 추천드립니다.

---

## 01. 기본 스텟 입력

현재 게임 내 스텟을 그대로 입력해주세요.

* 표기 힘 / 민첩 / 생명력 / 행운
* 공격력 / 공격력%
* 치명타 확률 / 치명타 공격력
* 체력 / 체력%
* 경험치 / 드랍률
* 스킬가속 / 보스 공격력 등

※ 체력 입력칸에는 이미 체력%가 적용된 현재 체력을 입력하면 됩니다.

---

## 02. 스텟 % 입력

현재 적용중인 스텟%를 입력하는 칸입니다.

예시:

* 힘 100%
* 민첩 80%
* 생명력 50%
* 행운 96%

---

## 03. 추가 스텟

잠재 / 진열대 / 장비 변경 등으로
추가되거나 빠질 예정인 스텟을 미리 계산할 수 있습니다.

음수 입력도 지원합니다.

예시:

* 공격력% +15
* 힘 -30
* 체력% +20

---

## 04. 단전

레벨에 따라 자동으로 단전 포인트가 지급됩니다.

* 상단전 → 체력 3% / 저항 1%
* 중단전 → 공격력 1%
* 하단전 → 드랍률 1.5% + 경험치 0.5%

남은 단전 포인트 이상으로 입력하면 경고가 표시됩니다.

---

## 05. 배분 스텟

추가로 투자할 스텟을 입력하는 칸입니다.

* 힘
* 민첩
* 생명력
* 행운

※ 이미 찍혀있는 스텟은 기입하지 마세요.
※ 포인트 빠른 조정으로도 쉽게 찍어볼 수 있습니다.

우측 결과창에서 최종 스텟 및 기대 공격력을 바로 확인할 수 있습니다.

---

# 최적화 기능

## ⚔️ 공격 최적화

남은 포인트와 단전을 가장 효율적으로 공격력 기대값에 투자합니다.

---

## 🛡️ 생존 최적화

목표 체력 / 물약 회복량 / 저항에 최대한 근접하도록 자동 배분합니다.

남은 포인트는 자동으로 공격 최적화에 사용됩니다.

※ 0 입력 시 해당 옵션은 무시됩니다.

---

## 🍀 경험치 / 드롭률 최적화

목표 예상 표기 공격력을 먼저 맞춘 뒤,

남은 포인트를:

* 경험치 효율
  또는
* 드롭률 효율

기준으로 자동 계산합니다.

행운 / 하단전 효율을 자동 비교하여 더 좋은 쪽으로 배분합니다.

---

# 스킬 DPM 계산

원하는 스킬의:

* 쿨타임
* 타수
* 배율

을 입력하면:

* 예상 1회 비 치명타 데미지
* 예상 1회 치명타 데미지
* 1분 DPM

을 계산할 수 있습니다.

보스 공격력 적용 ON/OFF도 지원합니다.

---

# 저장 기능

## ▣ 현재 값 저장

현재 입력값을 코드 형태로 복사합니다.

## ▣ 코드 가져오기

저장했던 코드를 붙여넣어 현재 세팅을 불러옵니다.

스킬 정보 / 단전 정보도 함께 저장됩니다.

---

# 기타 기능

* 자동 저장 지원
* 전체 초기화 지원
* 배분 스텟만 초기화 지원
* 단전 및 스텟 포인트 초과 경고 지원
