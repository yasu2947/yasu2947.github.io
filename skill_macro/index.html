FEATURES

주요 기능

캡처 캡처 설정

게임 화면에서 스킬바 전체 영역을 드래그로 지정합니다. 슬롯별 세부 범위도 개별 지정할 수 있습니다.

스킬바 ROI 슬롯 개별 범위 해상도 대응
매크로 설정 매칭 설정

매칭 임계값, 폴링 간격, 키 입력 딜레이, 슬롯 간 대기 시간을 세밀하게 조정합니다.

딜레이 세부설정
매크로 설정 스킬 슬롯

최대 7개 슬롯마다 키 바인딩, 발동 우선도, 스왑 2라운드 템플릿을 슬롯별로 설정합니다.

최대 7슬롯 발동 우선도 스왑 2라운드
매크로 설정 프리셋

빌드/사용처 별로 슬롯 설정을 저장하고 불러옵니다. 여러 세팅을 바꾸어가며 전환할 수 있습니다.

저장 / 불러오기 이름 지정
실행 1사이클 실행

버튼 클릭 또는 전역 단축키로 1사이클을 시작합니다. 실행 중 같은 키를 다시 누르면 중단됩니다.

1사이클 실행 전역 단축키
실행 레이드 모드

지속 사이클에 유휴 시간을 설정해 비는 스킬이 없도록 해주는 모드입니다.

자동 반복 즉시 스왑 쿨타임 대기

HOW TO USE

사용법

1

스킬바 영역 지정

캡처 설정 탭에서 게임 화면의 스킬바 전체를 드래그합니다. 슬롯 수(1~7)를 정하면 자동으로 균등 분할됩니다.

2

템플릿 이미지 등록

각 슬롯에서 스킬이 준비됐을 때의 이미지를 캡처해 slot_01_ready.png 형식으로 저장합니다. 스왑 스킬이 있으면 slot_01_swap.png도 등록합니다.

3

슬롯 & 키 설정

스킬 슬롯 탭에서 각 슬롯의 키 바인딩과 발동 우선도를 지정합니다. 스왑 2라운드를 쓰려면 해당 슬롯에서 스왑을 활성화합니다.

4

실행

실행 탭에서 [1사이클 실행] 버튼을 누르거나 전역 단축키를 입력합니다. 스킬이 준비되는 순간 자동으로 키가 입력됩니다.
